Rayload is a fast, private and customizable download manager for Android. It
runs a single Aria2 Next engine for HTTP, HTTPS, FTP, BitTorrent, Magnet,
Metalink and ED2K, with no ads, accounts or telemetry.

DOWNLOADING

- Multi-connection HTTP and FTP downloads with resumable transfers.
- BitTorrent and Magnet support with per-file selection and seeding controls.
- ED2K links through the same engine.
- Speed limits, scheduled limits and a keep-awake mode for long transfers.
- Downloads continue in a foreground service when the screen is off.

TASK LIST

- A mobile-first task list with a compact mode for large queues.
- Swipe left to delete and swipe right to pause, resume or share.
- Multi-select for batch pause, resume, delete and share.
- A detail page with progress, connections, peers, trackers and checksums.

CHECKSUMS

- MD5, SHA-1, SHA-256, SHA-512, BLAKE3, SM3 and CRC32 computed in one pass.
- A local digest cache returns finished checks instantly.
- Optional verification after download against published checksums from
  GitHub releases and CIRCL Hash Lookup.

MULTI-DEVICE

- Pair phones and computers over the local network with Ed25519 fingerprints.
- Push a task to a paired device, or watch its downloads alongside your own.
- Statistics for one device or every paired device.

PLUGINS

- Community JSON plugins parse links from sites that hide the real download.
- Plugins declare permissions, and every request is checked against a domain
  allow-list in a sandbox.

EXTRAS

- A headless Linux CLI for NAS and server deployments.
- 27 interface languages.
- A floating speed dashboard and home-screen statistics.

Rayload is an independent, unofficial Android port based on Rayburst by
AnInsomniacy. It is free software under the GPL-3.0, and the complete source is
published on GitHub.
