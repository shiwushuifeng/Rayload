Rayload 是一款快速、私密、可定制的安卓下载器。单个 Aria2 Next 引擎同时支持
HTTP、HTTPS、FTP、BitTorrent、Magnet、Metalink 与 ED2K，无广告、无账号、无遥测。

下载

- 多连接 HTTP / FTP 下载，支持断点续传。
- BitTorrent 与磁力链接，可选文件、可控做种。
- ED2K 链接由同一引擎处理。
- 限速、定时限速，以及长时间下载用的挂机模式。
- 息屏后下载在前台服务中继续。

任务列表

- 面向手机的任务列表，队列很长时可切换紧凑模式。
- 左滑删除，右滑暂停、继续或分享。
- 多选后可批量暂停、继续、删除、分享。
- 详情页展示进度、连接数、节点、Tracker 与校验值。

校验

- MD5、SHA-1、SHA-256、SHA-512、BLAKE3、SM3、CRC32 一次读盘全部算完。
- 本地缓存已算过的校验值，重复查看秒开。
- 可选下载后自动校验，比对 GitHub Release 与 CIRCL 公布的校验值。

多设备

- 用 Ed25519 指纹在局域网内配对手机与电脑。
- 可把任务推送到已配对设备，也能在本机查看对方下载进度。
- 统计页可分「本机」与「全部设备」查看。

插件

- 社区 JSON 插件解析网盘等隐藏真实地址的站点。
- 插件声明权限，每个请求都经过域名白名单校验，运行在沙箱中。

其它

- 面向 NAS 与服务器的无界面 Linux 命令行（CLI）。
- 27 种界面语言。
- 悬浮速度面板与桌面统计卡片。

Rayload 是基于 AnInsomniacy 的 Rayburst 的独立非官方安卓移植版，以 GPL-3.0
自由软件协议发布，完整源码公开在 GitHub。
