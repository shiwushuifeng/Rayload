# Rayload v1.0.4 Beta（合并测试版）

> 这是 `v1.0.4` 系列**全部测试版的合并归档**，标记为预发布。正式版见
> **`v1.0.4.1`**。

## 为什么合并

这一轮测试原本分散在多个 Release 里：

| 原发布 | 内容 |
| --- | --- |
| `v1.0.4`（曾被更名并标记为“Rayload v1.0.4 Beta”） | 事实上的 `beta1`：局域网、CLI、插件沙箱的首次落地 |
| `v1.0.4-beta2` | 局域网与 CLI 的早期迭代 |
| `v1.0.4-beta3` | 局域网修复与最终测试 |
| `v1.0.4-beta8` | 测试收官版：模块 1–4 新功能 + 真机反馈修复 + 插件导入修复 |

分散发布让用户难以判断该装哪个，也让 `1.0.4` 这个版本号被占用了一次。现在：

- 以上全部**合并为本 Release**，统一标记为预发布，作为测试线的历史归档。
- 版本号 `1.0.4` 归还给正式线，正式版改号为 **`1.0.4.1`**。
- 本 Release 的资产取各版本中**最新的一份**（APK 取自 beta8，CLI 取自 1.0.4），
  避免同一变体堆叠多个旧包。

## 资产说明

| 文件 | 用途 |
| --- | --- |
| `v1.0.4-beta8-full-arm64.apk` | 完整功能（局域网 + 插件引擎） |
| `v1.0.4-beta8-lite-arm64.apk` | 精简版，不含插件引擎与局域网 |
| `v1.0.4-beta8-fdroid-arm64.apk` | F-Droid 构建，独立包名 `com.shiwushuifeng.rayload.fdroid` |
| `v1.0.4-beta8-full-x86_64.apk` | 模拟器 / x86_64 设备 |
| `v1.0.4-beta8-demo-arm64.apk` | 展示版，内置演示数据 |
| `rayload-cli-v1.0.4-linux-x86_64.tar.gz` | Linux x86_64 命令行（`ray` / `rayload-cli`） |

## 测试版期间完成的事

- **真机滑动**从 pointer 事件改为触摸事件驱动，修掉 Android WebView 的
  `pointercancel` 中断；左滑删除、右滑暂停/继续/推回本机/分享。
- **设备配色**统一为按设备身份派生的单一颜色，设置页、任务彩条、详情页、取色器一致。
- **高级校验系统**：七种算法、SQLite 缓存、可取消、导出、BT 多文件、在线查询、
  下载后自动校验。
- **插件导入**修复（`content://` URI、文件名归一、脚本入口隔离、行 JSON 协议）。
- **布局**：设置页移动端 Tab、宽屏限宽、底栏单行、平板图表并排。
- **CLI** 可脚本化：稳定退出码、`--json`、批量添加、`watch`。

完整逐条说明见仓库 `docs/RELEASE_NOTES.md`，以及本 Release 对应的
`docs/releases/v1.0.4-beta-merged.md`。

# Rayload v1.0.4 Beta (merged test builds)

> A single archive of **every test build** in the `v1.0.4` line, marked as a
> pre-release. The official release is **`v1.0.4.1`**.

## Why they are merged

The test builds were spread across `v1.0.4` (which had been renamed to
"Rayload v1.0.4 Beta" and served as `beta1`), `v1.0.4-beta2`, `v1.0.4-beta3`
and `v1.0.4-beta8`. That made it hard to know which package to install and it
consumed the `1.0.4` version number.

Now every test build lives in this single pre-release, `1.0.4` is free again, and
the official release carries the unambiguous version **`1.0.4.1`**. Assets here
are the newest of each kind: APKs from beta8, CLI from `v1.0.4`.

## What the test builds delivered

Real-device swipe on touch events, one identity-derived device color, the
seven-algorithm checksum system with cache and published-digest lookup, the
plugin import repair (`content://` URIs, name normalisation, script namespacing,
the line-JSON protocol), responsive settings and tablet layouts, and a scriptable
`ray` CLI.
